# InvestmentRegulation.ca

InvestmentRegulation.ca is a free, open-source study resource for Canada's Canadian Investment Regulatory Exam. It includes 69 plain-language lessons, lesson checks, a 100-question bank, flashcards, drills, mock exams, a glossary, and local progress tracking.

Visit [investmentregulation.ca](https://investmentregulation.ca).
